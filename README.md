# LSZDev — Portfólio

Portfólio pessoal de **Luis Henrique (LSZDev)**, estudante de Análise e Desenvolvimento de Sistemas no Grupo Unis. O site apresenta sua trajetória, serviços, tecnologias, projetos em andamento e canais de contato.

## Sobre o projeto

O LSZDev reúne informações sobre desenvolvimento de landing pages, desenvolvimento web e de softwares, além de práticas de qualidade (QA). O layout é responsivo, com tema escuro, partículas interativas e suporte à preferência por movimento reduzido.

## Tecnologias

- HTML5 semântico
- CSS3 responsivo e animações
- JavaScript sem dependências de build
- Canvas para o fundo de partículas
- Ícones do Simple Icons via jsDelivr

## Executar localmente

Abra `index.html` diretamente no navegador ou inicie um servidor estático na raiz do projeto. Por exemplo, com Python:

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Publicar no Render

O arquivo `render.yaml` configura o projeto como um Static Site. Conecte este repositório no Render e crie um Blueprint a partir do arquivo. O site é publicado diretamente da raiz, sem etapa de build.
