# LSZDev

**MEU PORTIFOLIO PESSOAL**, sou estudante do quarto período de Análise e Desenvolvimento de Sistemas no Grupo Unis. O site apresenta seu foco em desenvolvimento web e de softwares, os serviços que oferece, tecnologias com que trabalha, projetos em andamento e formas de contato.

## Objetivo

O LSZDev foi criado para dar contexto ao meu serviço e facilitar o primeiro contato com pessoas e negócios que precisam construir ou melhorar sua presença digital. A página explica cada serviço e mostra os projetos e ferramentas utilizados, sem depender de uma aplicação de back-end.

## Serviços apresentados

- **Landing pages:** páginas para apresentar negócios, produtos ou serviços, organizar informações importantes e orientar visitantes a entrar em contato.
- **Desenvolvimento web e de softwares:** criação de experiências digitais responsivas, com estrutura e funcionalidades adequadas ao objetivo de cada projeto.
- **Qualidade (QA):** revisão de navegação, links, formulários, comportamento e apresentação em diferentes tamanhos de tela.

## Projetos

O portfólio destaca a própria página LSZDev e o **Conecta Unis**, projeto acadêmico em desenvolvimento para aproximar estudantes, egressos e empresas de oportunidades de emprego, estágio, eventos e desenvolvimento profissional. Também reserva espaço para projetos futuros.

## Tecnologias e ferramentas

As ferramentas estão agrupadas de acordo com a etapa em que são utilizadas:

### Interface e experiência

- **HTML:** organiza o conteúdo e a estrutura das páginas.
- **CSS:** define a apresentação visual, o layout e a adaptação a diferentes telas.
- **JavaScript:** adiciona interações e comportamentos à página.
- **TypeScript:** permite escrever JavaScript com tipos, ajudando a estruturar aplicações maiores.
- **React:** biblioteca para construir interfaces a partir de componentes reutilizáveis.
- **Figma:** apoio a UI/UX, organização visual e prototipação de interfaces.

### Back-end e dados

- **Node.js:** ambiente para executar JavaScript no servidor e construir serviços back-end.
- **APIs REST:** definem formas de sistemas trocarem dados por meio de requisições HTTP.
- **Python:** linguagem de programação de uso geral, aplicável a scripts e desenvolvimento back-end.
- **Supabase:** plataforma que oferece recursos de banco de dados e serviços de back-end.

### Publicação e hospedagem

- **Railway e Vercel:** plataformas para publicar aplicações e disponibilizá-las pela internet.
- **Domínio `.com.br`:** endereço personalizado que pode apontar para o site publicado.

As tecnologias listadas representam ferramentas estudadas e utilizadas nos projetos. A stack do Conecta Unis está em consolidação durante o desenvolvimento.

## Interface e recursos

- Layout responsivo para celular e desktop.
- Navegação por âncoras entre as seções Sobre mim, Serviços, Tecnologias, Projetos e Contato.
- Fundo de partículas em canvas com interação sutil ao movimento do cursor.
- Indicador de progresso de leitura e revelação gradual de conteúdo ao rolar a página.
- Respeito à preferência do dispositivo por movimento reduzido.
- Links para GitHub, WhatsApp, Instagram e Discord.

## Implementação

O site é uma página estática implementada com HTML, CSS e JavaScript, sem dependências de build ou serviço back-end próprio. Os ícones de tecnologias e redes são carregados do Simple Icons via jsDelivr.

O arquivo `render.yaml` descreve a publicação como Static Site no Render, servindo os arquivos da raiz do repositório.
